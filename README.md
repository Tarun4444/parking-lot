Parking Lot (Java)
===================

Simple parking lot example Java project.

How to build
--
If you have Java installed you can compile and run from the project root:

```
javac -d out $(find src -name "*.java")
java -cp out com.example.parkinglot.Main
```

Alternatively import the `src` tree into your IDE (IntelliJ, Eclipse).

Notes
--
- Source is under src/main/java/com/example/parkinglot.
